# Things Atlas · 日常之物图志

[中文](README.md) · [English](README.en.md)

Things Atlas explores the invention, patenting, mass production, and popularization of everyday objects through a world map and an interactive timeline. Discover when and where familiar objects became part of daily life. The collection includes everyday objects as well as foods and beverages that are widely integrated into daily life, such as tofu and tea.

Foods and beverages may also include specific branded products with broad cultural reach. Entries must distinguish food types from branded products and document their origins, production, launch, or popularization using evidence. A brand's launch date is not the invention date of the entire food type.

## Features

- **Explore the map**: Discover places associated with invention, patents, mass production, and popularization. Lines connect locations linked to the same object.
- **Browse the timeline**: Drag the timeline to see objects that had appeared by the selected year. Use the arrow keys to move one year at a time, or hold Shift to move ten years.
- **Filter by category**: Filter objects on the map and timeline by category and see how many are currently visible.
- **Search objects**: Search the full collection by Chinese or English name and open object details. If there are no matches, suggest an object through a GitHub Issue with the title prefilled as `add: {keyword}`.
- **View object details**: Explore photos, summaries, key dates, related places, and reference sources.
- **Explore disputed histories**: Show or hide disputed entries and view dispute notes and date precision in the details.
- **Switch languages**: Browse in Chinese or English.
- **Share links**: Share an object's detail link with the selected year, categories, and language preserved.

The basemap uses modern political borders. Historical locations are approximate.

## Contribute

### No coding needed: open an Issue

If you would like an object added, please submit an [Issue](https://github.com/gitdust/things-atlas/issues/new). **Only the object's name is required**; a detailed description and references are optional.

### Contribute an entry: Fork and open a PR

[Fork this repository](https://github.com/gitdust/things-atlas/fork), clone your fork, create a branch, and follow the [item contribution workflow](CONTRIBUTING.md#add-an-item). Then open a Pull Request against this repository. The workflow covers research, bilingual fields, image licensing, generated assets, and validation; you can also hand it directly to an AI agent.

In your cloned repository, give your AI agent this task, replacing the object name:

```text
Read CONTRIBUTING.md first and follow its Add an item workflow to add
"OBJECT NAME". Check for duplicates, verify historical sources online,
and complete bilingual text, dates, locations, references, and licensed images.
Generate the required image variants, indexes, and fonts, and run applicable checks.
Do not invent origins, dates, locations, or image licenses. Change only this entry
and necessary generated files. Report changes, checks, and anything unverified,
and prepare a PR description for my review.
```

Before submitting, review the agent's facts, references, and image licenses yourself. Explain your date choices and any disputes in the PR.
