# Things Atlas · 日常之物图志

[中文](README.md) · [English](README.en.md)

Things Atlas 通过世界地图与时间轴，展示日常物品的发明、专利、量产与普及历程，探索熟悉之物在何时、何地走进日常生活。收录范围包括日常用品，以及豆腐、茶等广泛融入日常生活的食品与饮料。

食品与饮料也可以是具有广泛影响的具体品牌产品。条目需区分食品类型与品牌产品，分别记录有据可查的起源、生产、上市或普及历程，不能把某个品牌的上市时间当成整类食品的发明时间。

## 站点功能

- **地图探索**：查看物品的发明地、专利地、量产地与普及地，通过地点连线了解同一物品的多地关联。
- **时间轴浏览**：电脑端拖动时间轴，查看截至所选年份已出现的物品；选择目录条目时同步到其主年份。移动端隐藏时间轴，通过目录浏览。
- **年代目录**：在面板中按年代浏览全部条目，搜索不受地图年份影响；打开详情后，关闭即可返回原来的目录位置。
- **物品搜索**：按中文或英文名称搜索全部物品并打开详情；没有匹配结果时，可跳转到 GitHub Issue 建议添加，标题自动填入 `add: {keyword}`。
- **物品详情**：查看物品图片、简介、关键年份、相关地点与参考来源。
- **争议信息**：在目录中识别争议条目，并在详情中查看争议说明与年代精度。
- **版本更新**：标题旁显示当前版本；检测到新版时显示绿色刷新提示，点击更新后展示本次版本内容，历史变更记录保留在仓库中。
- **多语言**：中文、英文、西班牙语、日语。中文是默认地址；其余语言使用 `/en/`、`/es/`、`/ja/`。条目正文尚无西语或日语译文时显示英文。
- **链接分享**：分享物品详情链接，保留所选年份与语言。

地图底图采用现代国界，历史地点为近似定位。

## 参与贡献

### 不会编程：提交 Issue

如果有希望添加的物品，请在 [Issues](https://github.com/gitdust/things-atlas/issues/new) 中提交，**只需提供物品名称**，详细描述和参考资料均为可选。

### 会编程：新建分支并提交 PR

只需克隆仓库后直接新建 `feature/{item name}` 分支，按照 [条目添加流程](CONTRIBUTING.md#add-an-item) 补充条目，再提交 Pull Request。该流程包含资料核实、中英文字段、图片授权、数据生成和验证要求，也可以直接交给 AI agent 执行。界面另有西班牙语和日语。

在克隆后的仓库中，把下面的任务交给 AI agent（替换物品名称）：

```text
请先阅读仓库的 CONTRIBUTING.md，严格按照其中的 Add an item 流程，
新建 feature/{item name} 分支并为「物品名称」新增条目。先检查是否重复，再联网核实历史资料，补齐中英文、
年代、地点、来源及授权图片；生成所需图片版本、索引和字体，完成适用验证。
不要编造起源、年代、地点或图片许可。只修改本条目及必要的生成文件，
完成后说明改动、验证结果和未验证项，并整理 PR 描述供我检查。
```

提交前请自行核对 AI 生成的事实、引用和图片授权，并在 PR 中说明年代选择与争议。
